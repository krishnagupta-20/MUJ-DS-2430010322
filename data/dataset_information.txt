DATASET INFORMATION
===================

Name        : Fashion-MNIST
Authors     : Xiao, Rasul, Vollgraf (Zalando Research), 2017
Reference   : "Fashion-MNIST: a Novel Image Dataset for Benchmarking Machine Learning
              Algorithms", arXiv:1708.07747
Licence     : MIT (check https://github.com/zalandoresearch/fashion-mnist before redistribution)
Task        : 10-class image classification (clothing and footwear articles)

How the data is obtained
------------------------
No manual download is needed and the dataset is NOT stored in this folder.
src/preprocessing.py calls keras.datasets.fashion_mnist.load_data(), which downloads the
files on first use and caches them under ~/.keras/datasets/. An internet connection is
required the first time only.

Contents
--------
Image size      : 28 x 28, grayscale, uint8 (0-255)
Official split  : 60,000 training images + 10,000 test images
Classes (label) : 0 T-shirt/top   1 Trouser   2 Pullover   3 Dress     4 Coat
                  5 Sandal        6 Shirt     7 Sneaker   8 Bag       9 Ankle boot
Class balance   : perfectly balanced - 6,000 training and 1,000 test images per class
                  (imbalance ratio 1.0, so no resampling or class weighting is used)

Split used in this project (seed 42)
------------------------------------
Train       : 54,000  (90% of the official training set, stratified)
Validation  :  6,000  (10% of the official training set, stratified)
Test        : 10,000  (official test set; used only for final evaluation, never for
                       model or hyper-parameter selection)

Preprocessing
-------------
1. Pixel values divided by 255 -> float32 in [0, 1]
2. Channel axis added -> shape (28, 28, 1)
3. Augmentation (training only, built into each model): RandomFlip(horizontal) and
   RandomTranslation(10%). Identical for all five models.
Labels are integers 0-9 (sparse categorical cross-entropy).

Regenerating the dataset analysis
---------------------------------
    python src/preprocessing.py
writes results/class_distribution.csv, figures/class_distribution.png and
figures/sample_images.png.
